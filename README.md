### 🛠️ Technical Approach
My goal is to document not just "how" to build systems, but the "why" behind the security and architectural decisions. Each project follows the same standard:
*   **Design & Provisioning** — architecture, network layout and setup steps.
*   **Security Best Practices** — hardening, least privilege and attack simulation.
*   **Root Cause Analysis (RCA)** — every incident logged with symptom, root cause and resolution.
